# milon-admin

Web admin dashboard for **MILON**, a fitness and nutrition app.

Built with Vite, React, TypeScript, Tailwind CSS, React Router, TanStack Query, react-hook-form + zod and Recharts. There is no backend yet: data comes from mock services in `src/features/*/api`, which can be swapped for real endpoints later.

## Getting started

```bash
npm install
npm run dev
```

Demo login: `alex.martin@example.com` with any password of 8+ characters; any 6-digit code passes two-step verification.

## Scripts

- `npm run dev` – start the dev server
- `npm run build` – type-check and build for production
- `npm run preview` – preview the production build
